# Ámbar Atelier

Sitio web oficial de **Ámbar Atelier — Arquitectura · Diseño · Construcción**.

> *"Casas contemporáneas pensadas para el lugar, la luz y la forma de vivir de cada familia."*

## 🏛️ Sobre el Proyecto

Ámbar Atelier es una propuesta de arquitectura residencial contemporánea centrada en el aprovechamiento de las condiciones naturales de cada terreno (sol, viento, vistas y vegetación) mediante materialidad honesta y diseño cálido (madera, hormigón, acero, vidrio).

### Especialidades:
- **Casa en parcela**: Terreno, vistas, privacidad.
- **Casa de playa**: Sol, viento, terrazas.
- **Segunda vivienda**: Simple, cálida, funcional.
- **Remodelación**: Reordenar, ampliar, renovar.

## 🛠️ Tecnologías

- **HTML5 semántico** y moderno
- **CSS3 nativo** (Custom properties, CSS Grid, Flexbox, Fluid Typography con `clamp()`, animaciones sutiles y diseño responsive mobile-first)
- **Vanilla JavaScript** (Intersection Observer API para transiciones *reveal*, barra de progreso y parallax sutil)
- **Tipografías**: DM Sans, Inter Tight, Libre Caslon Display (Google Fonts)

Desarrollado con criterio de diseño editorial y minimalismo contemporáneo.
